如何在 App Store Connect 创建 App

下面按实际后台操作顺序整理。建议边看边打开对应控制台页面，逐项完成。

适用场景

在 App Store Connect 创建 App 记录。

操作步骤

  1. App Store Connect → 我的 App → 添加。
  2. 填写名称、主要语言、套装 ID、SKU。
  3. 选择用户访问权限。
  4. 创建后补齐定价、类别、隐私政策、截图等。
  5. 在 Xcode 用同一套装 ID 归档上传。

注意事项

  • 套装 ID 与证书/描述文件需匹配。
  • SKU 对用户不可见但需唯一。
  • 名称需通过审核且避免商标冲突。
